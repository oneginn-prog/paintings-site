# ТЗ: сайт картин «Вадим Гусев»

## 0. Коротко
Тихая онлайн-галерея одного художника. Только живопись, только оригиналы, каждая работа — в единственном экземпляре. Без корзины и онлайн-оплаты: покупатель выбирает картину, смотрит её в интерьерах и пишет автору в Telegram или на почту.

- Данные о картинах: `catalog.md` (в корне репозитория).
- Материалы: папка `materials/`
  - `materials/paintings/` — обработанные фото 11 картин (обрезаны по холсту, цвет выровнен);
  - `materials/interiors/` — 37 готовых интерьеров с картинами, по папкам картин;
  - `materials/portrait.jpg` — портрет автора;
  - `materials/details/` — фото боковых сторон и фактуры (крупные планы мазков, торцы холста), по подпапкам с названиями картин. Также детали «Мыслей об осени» лежат в `materials/paintings/11_Мысли-об-осени_детали/`. Если для картины деталей нет — блок деталей на её странице просто не показывается.
- Файлы в `materials/` — исходники. Не меняй и не удаляй их; для сайта делай из них оптимизированные копии.
- Если не можешь однозначно сопоставить файл с картиной из каталога — спроси меня, не угадывай.

## 1. Стиль
- Ориентир — шаблон ArtFrame (https://artframe.framer.website/): ультраминимализм, много воздуха, тонкая типографика, элегантные заголовки с выделением одного слова курсивом, полупрозрачная подложка поверх фото на главном экране.
- Копировать нужно настроение и приёмы, а не сам шаблон: никаких их текстов, логотипа, изображений.
- Тон: тихий, сдержанный, тёплый.
- Палитра: белый / тёплый светлый фон, тёплый серый, почти чёрный текст. Картины — главные цветные пятна.
- **Акцентный цвет: #002FA7 (синий Кляйна).** Только малыми дозами: выделенные курсивом слова в заголовках, кнопки, ссылки при наведении, тонкие линии. Никаких больших синих плашек и фонов.
- Шрифты: элегантная антиква (serif) для заголовков с хорошим курсивом + спокойный гротеск для текста. Обе должны полноценно поддерживать кириллицу (например, Cormorant Garamond / Playfair Display + Inter / Manrope — на твой выбор).
- Адаптивность: сайт должен отлично выглядеть на телефоне (большая часть покупателей придёт с телефона).

## 2. Техническая часть
- Статический сайт на GitHub Pages, сборка и публикация через GitHub Actions. Подойдёт генератор статических сайтов (например, Astro или Eleventy) — данные о картинах в одном файле данных, страницы генерируются из него.
- Две языковые версии:
  - русская — основной адрес (`/`, `/works/<slug>/`);
  - английская — отдельный каталог `/en/` (`/en/`, `/en/works/<slug>/`) с полностью переведёнными текстами.
  - Переключатель RU / EN в шапке ведёт на ту же страницу в другом языке.
- Изображения: WebP + запасной JPEG, адаптивные размеры (`srcset`): ~600 px (миниатюры), ~800 px (телефон), ~1200 px (компьютер), 2048 px только для увеличения по клику. Ленивая загрузка (`loading="lazy"`) везде, кроме первого экрана.
- Базовое SEO: title/description на каждой странице, Open Graph-картинка, `lang` и `hreflang` для RU/EN, понятные `alt` у картинок.
- Архитектура должна позволять позже добавить раздел «Истории картин» (блог). **Сейчас он нигде не виден** — ни в меню, ни на странице, никаких заглушек «скоро».
- Не добавляй: корзину, оплату, рассылку, отзывы, cookie-баннеры, аналитику, юридические страницы.

## 6. Примерка на свою стену
Работает целиком в браузере, фото покупателя никуда не отправляется (это нужно написать мелким текстом в окне примерки).
1. Покупатель загружает фото своей стены (с телефона можно сразу сфотографировать).
2. Калибровка масштаба: покупатель проводит линию по предмету известной ширины (диван, дверь, комод) и вводит его ширину в сантиметрах. Есть подсказка, как это сделать.
3. Картина появляется на фото в реальном масштабе (по размерам из каталога). Её можно перетаскивать; размер подстраивается под калибровку, но есть ручная подстройка.
4. Мягкая реалистичная тень от картины: переключатель «свет слева / справа», ползунок мягкости. Глубина подрамника/рамы для тени: «Абстракция №1», «Абстракция №2», «Мысли об осени» — 4 см; «Лес», «Дорога» — 5 см; остальные — 2 см.
5. Кнопки: «Сохранить картинку» (скачать результат) и «Написать о картине».
6. Для диптихов — обе картины, двигаются вместе, с регулируемым промежутком.
7. Удобно на телефоне (касания, щипок для масштаба).
