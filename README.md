# Сайт картин Вадима Гусева

Статический сайт-галерея: русская версия по адресу `/`, английская по адресу `/en/`.
GitHub сам собирает и публикует его на GitHub Pages после каждого изменения в ветке `main`.

## Где что лежит

| Что | Где |
|---|---|
| Все данные о картинах: названия, размеры, цены, техника, фото | `src/_data/catalog.json` |
| Все тексты сайта на двух языках (главная, FAQ, кнопки) | `src/_data/i18n.json` |
| Контакты (Telegram, почта) | `src/_data/site.js` |
| Исходные фото (их не трогаем) | `materials/` |
| Оформление (цвета, шрифты, отступы) | `src/assets/css/style.css` |
| Шаблоны страниц | `src/_includes/`, `src/index.njk`, `src/works.njk` |
| Примерка на стену | `src/assets/js/tryon.js` |
| Сборка и публикация | `.github/workflows/deploy.yml` |

## Как поменять цену или текст

1. Откройте на GitHub нужный файл, например `src/_data/catalog.json`.
2. Нажмите на значок карандаша (Edit).
3. Исправьте число или текст. Кавычки и запятые не трогайте.
4. Нажмите зелёную кнопку **Commit changes**.
5. Через 2–5 минут изменения появятся на сайте. Ход публикации видно на вкладке **Actions**.

## Как добавить новую картину

1. Положите фото картины в `materials/paintings/`, интерьеры в отдельную папку внутри `materials/interiors/`,
   а фото деталей (если есть) в отдельную папку внутри `materials/details/`.
2. Добавьте в `src/_data/catalog.json` новый блок по образцу соседних (`slug` — латиницей, он попадёт в адрес страницы).
3. Новая картина сама появится в сетке, получит русскую и английскую страницы и примерку.

## Запуск на своём компьютере (по желанию)

Нужен Node.js 22. Дальше:

```
npm install
npm start
```

Сайт откроется по адресу http://localhost:8080. Первый запуск дольше обычного (около 3 минут):
в это время из исходных фото готовятся уменьшенные копии.
